# Notes de version — Mon Coffre 1.0.0

**Date de sortie :** 15 juillet 2026
**Plateforme :** Android
**Type de version :** Première version stable

## En résumé

Mon Coffre est une application de gestion financière familiale qui permet de suivre l'argent d'un même compte bancaire réparti entre plusieurs propriétaires (Personnel, Papa, Église, Autres…), ainsi que les cotisations d'église. Toutes les données restent **sur votre téléphone**, sans compte à créer et sans connexion internet requise.

## Ce que vous pouvez faire dès aujourd'hui

- Suivre le solde de chaque catégorie et le solde global de votre compte en un coup d'œil sur le Dashboard.
- Créer vos propres catégories en plus des catégories par défaut (Personnel, Papa, Église, Autres).
- Enregistrer vos entrées et sorties d'argent, les rechercher, les filtrer et les trier.
- Suivre les cotisations d'église (sème et funérailles) avec des statistiques dédiées.
- Consulter l'historique complet de votre activité sous forme de chronologie.
- Visualiser des statistiques utiles : moyenne mensuelle, catégorie la plus active, taux d'épargne.
- Sauvegarder toutes vos données dans un fichier, le partager où vous le souhaitez, et le restaurer à tout moment.
- Protéger l'application avec un code PIN et, si votre téléphone le permet, votre empreinte digitale ou votre visage.

## Confidentialité

- Aucune donnée n'est envoyée sur internet : l'application fonctionne entièrement hors-ligne.
- Aucun compte, aucune inscription, aucun suivi publicitaire.
- Le code PIN est stocké de façon chiffrée sur votre appareil uniquement, et n'est jamais inclus dans vos sauvegardes.

## Points d'attention

- L'application est disponible en français uniquement pour le moment.
- Les graphiques visuels dans l'écran Statistiques seront ajoutés dans une prochaine version (les chiffres clés sont déjà disponibles).
- Pensez à activer la sauvegarde régulière de vos données : en cas de perte ou de changement d'appareil, seule une sauvegarde exportée permet de récupérer votre historique.

## Assistance

Pour toute question sur l'utilisation de l'application, consultez le fichier `README.md` du projet, qui détaille l'ensemble des fonctionnalités et la procédure de sauvegarde/restauration.
